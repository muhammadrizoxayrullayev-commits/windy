# 🌬️ Windy — Aerodynamic Multi-Language Typing Platform

Windy is a modern, high-performance, aerodynamic typing speed test platform with multi-language support, creamy mechanical switch soundscapes (ASMR Thock), smooth caret physics, and 24/7 offline reliability.

---

## ✨ Features
- **🌍 Multi-Language Support**:
  - Uzbek (Lotin & Kirill)
  - English (Top 1000 & Quotes)
  - Russian (Русский)
  - Japanese (Romaji / Hiragana)
  - Arabic (العربية) with native RTL support
- **🎧 ASMR Mechanical Switch Audio Engine**:
  - Pre-baked Web Audio API synthesis (Zero-Latency)
  - Soft, creamy Lubed Linear Thock (Gateron Oil King / Ink Black)
  - NovelKeys Cream, Kailh Box Clicky, Bubble Marbles & Vintage Typewriter
  - Soft, velvety damped acoustic typo feedback (fatigue-free)
- **📱 100% Android & Mobile Support**:
  - Native virtual keyboard IME support (Gboard, Samsung Keyboard)
  - Zero auto-zoom (`maximum-scale=1.0`)
  - Compact viewport mode for mobile typing
- **⚡ Zero-Lag Aerodynamic Cockpit**:
  - Hardware-accelerated GPU translate3d caret
  - Live HUD with WPM, Accuracy, Streak & Time
  - Instant CapsLock warning alert
  - Wind stream particle canvas background
- **🎨 6 Hand-Crafted Futuristic Themes**:
  - Windy Frost, Cyber Breeze, Dark Zephyr, Sakura Gale, Serika Wind, Nordic Sky
- **🔒 24/7 Safe & Private**:
  - 100% client-side execution, zero external trackers, safe local storage persistence.
